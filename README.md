# 🛒 Shopping Cart System

A simple console-based **Shopping Cart System** developed in Java using the `LinkedList` collection.

This mini project demonstrates basic **Object-Oriented Programming (OOP)**, collection handling, and CRUD operations through a menu-driven application.

## ✨ Features

- ➕ Add new items to the cart
- 🗑️ Remove items by name
- 🔄 Update item quantity
- 💰 Update item price
- 🔎 View the first and last added items
- 📋 Display all cart items
- 🧾 Calculate the overall total bill
- ⚠️ Handle invalid user input

## 🛠️ Technologies & Concepts

- **Java**
- **LinkedList**
- **Iterator**
- **OOP**
- **CRUD Operations**
- **Menu-Driven Programming**
- **User Input Validation**
